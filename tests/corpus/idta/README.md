# Official IDTA material as test corpus

`example.json` / `example.aasx` are the published IDTA 02004 2.0
Handover Documentation examples, unmodified, vendored under CC BY 4.0
(© IDTA and contributors — see THIRD_PARTY.md for the pin and hashes).

They are here *with their defects*: the suite pins what this validator
reports against them by name, because the published reference material
is exactly the input a real-world tool meets first. Repaired variants
used as passing fixtures are built in the tests, with each repair named.
